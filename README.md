# spb-facades

Генератор фасадов петербургских доходных домов (Адмиралтейский район). Выбираете один из шести типов, ширину фасада и этажность — генератор строит обмерный чертёж главного фасада в SVG: оси с номерами, отметки, размерные цепочки и линию предела 23,5 м. Карниз выше 23,5 м генератор не строит. Только фасад, без 3D.

## Откуда данные

- **Размеры** — из альбома [`facades.html`](facades.html) («Шесть фасадов Адмиралтейского района», 1817–1956; [`facades.pdf`](facades.pdf) — та же версия для печати). **Чертежи альбома — реконструкция по фотографиям из открытых источников и контурам OpenStreetMap, выполненная с помощью ИИ (Claude). Это не натурный обмер; высоты — с точностью ±0,5 м.** Из альбома взяты только размеры: оси, высоты, окна, членения. Они собраны в [`data/styles.json`](data/styles.json); мелкие размеры (подоконники, ширины проёмов, пояса) сняты с геометрии чертежей. Чего в альбоме нет — `null`.
- **Правила** — автора проекта, [`my_rules.md`](my_rules.md): что в каждом стиле обязательно, что можно менять, что не берётся и что запрещено. Это главный источник логики генератора. Как реализовано каждое правило, ответы автора на вопросы и принятые технические решения — [`docs/implementation.md`](docs/implementation.md). Решения автора, которых нет в альбоме (высоты этажей 02, число колонн портика 01, рост модерна 04), лежат в `data/styles.json` отдельно, в блоке `generator`.

## Как открыть

Страница статическая, без сборки и зависимостей. Ей нужно прочитать `data/styles.json`, а браузер не даёт странице, открытой как файл, читать соседние файлы. Поэтому:

1. В папке проекта запустите любой статический сервер, например:

   ```bash
   python3 -m http.server 8000
   ```

2. Откройте <http://localhost:8000/>.

Можно опубликовать папку через GitHub Pages — тоже без сборки. Если открыть `index.html` двойным щелчком, страница предложит выбрать `data/styles.json` вручную.

Состояние генератора записывается в адрес страницы (`#s=02&w=35.9&n=4&step=2.24`), так что вариантом можно поделиться ссылкой. Кнопка «Скачать SVG» сохраняет чертёж; размер листа задан в миллиметрах в масштабе чертежа (1:200, 1:400, 1:500 или 1:1000).

## Проверки

```bash
node tests/check.mjs
```

Node 18+, без зависимостей. Проверяет 200 случайных фасадов (воспроизводимо, `--seed N`, `--count N`): ни один элемент, кроме аттика, кровли и скульптуры, не выше 23,5 м; оси внутри ширины; окна, двери и ворота не пересекаются и не выходят за фасад. Геометрия проверяется заново, независимо от проверок самого генератора. Ещё проверяет, что запросы выше предела отклоняются, что шесть домов альбома воспроизводятся (ширина, число осей, отметка карниза) и что [`docs/validation.md`](docs/validation.md) не устарел. Если поменяли данные или генератор:

```bash
node tests/validation.mjs --write
```

## Ограничения

- Размеры — реконструкция ИИ по фото, ±0,5 м; генератор не точнее альбома и не заменяет обмер и проект.
- Шесть типов — по одному дому каждый. Генератор не придумывает элементы, которых нет у дома своего типа: брать их у других домов запрещает правило о смешении стилей.
- Где в альбоме одна серия окон, вариантов окон нет — по решению автора. У дома 02 нет пилястр, балконов и эркеров.
- Как фасад растёт по этажности и как растёт модерн, задал автор; остальные способы подбора под ширину (поля, шаг, число осей) — технические решения, они перечислены в [`docs/implementation.md`](docs/implementation.md). Если у модерна или портика классицизма расстояния между осями приходится растянуть или сжать больше чем на 25 % (модерн шире ~29,5 м, классицизм шире ~100 м или уже ~80 м), под чертежом появляется примечание.
- Ширина — до 150 м; этажность — только та, при которой карниз или парапет не выше 23,5 м и есть все обязательные элементы стиля. Аттик, кровля и скульптура могут быть выше предела.
- Мелкий декор нарисован условно, цвет и материал не передаются. Только главный фасад в ортогональной проекции.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | страница генератора |
| `src/generator.js` | раскладка, проверки правил, рендер SVG; работает в браузере и в Node |
| `data/styles.json` | параметры шести типов со ссылками на дома альбома |
| `docs/implementation.md` | правило (дословно) → реализация → параметры; вопросы автору |
| `docs/validation.md` | сверка «альбом / генератор / расхождение» |
| `tests/check.mjs`, `tests/validation.mjs` | проверки и сборка таблицы сверки |
| `facades.html`, `facades.pdf` | исходный альбом |
| `my_rules.md` | правила автора |
