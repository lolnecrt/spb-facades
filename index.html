Генератор фасадов · Адмиралтейский район · без 3D

Фасад доходного дома по шести типам

Выберите тип, ширину фасада и этажность — генератор построит обмерный чертёж: оси с номерами, отметки, размерные цепочки и линию предела 23,5 м. Карниз выше предела генератор не построит.

Откуда размеры. Из альбома «Шесть фасадов Адмиралтейского района» (PDF): реконструкция по фотографиям и контурам OpenStreetMap с помощью ИИ, не натурный обмер, высоты ±0,5 м.

Откуда логика. Из правил автора проекта (my_rules.md). Как каждое правило реализовано — docs/implementation.md.

      Проверка: генератор воспроизводит дома альбома

      С параметрами каждого дома (тип, ширина, этажность, варианты по умолчанию) генератор должен дать ту же ширину, то же число осей и ту же отметку карниза. Таблица считается здесь же, в браузере; та же таблица — в docs/validation.md.
